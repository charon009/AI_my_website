关于我

About

你好，我是杨鑫科——一个喜欢把想法变成网页的前端折腾者。

从 HTML、CSS、JavaScript 起步，我用一个个小页面和小 demo 练手：把随手冒出来的想法写成能打开的网页，是我最上瘾的事。

这个主页本身，就是用原生 HTML / CSS 手写的——没有框架，没有构建工具，所见即所得。

现在在做

  • 维护练手小窝 —— 把前端练习、实验性 demo 和奇怪想法都收进 my-webpage 仓库，随缘更新。
  • 搭建个人主页 —— 就是你现在看的这个页面，迭代式地把它做成自己的网络名片。
  • 继续学前端 —— 往框架、工具链和交互动效的方向探索，保持动手。

写点什么

信奉「先动手，再完美」。一个页面跑起来，比十个方案停在文档里更有意义。
